# Isadora Rosalém · personal website

Static site (HTML, CSS and JavaScript, no build step). Open `index.html` in a browser, or publish the folder on GitHub Pages.

- **Pages**: `index.html`, `research.html`, `experience.html`, `life.html`. All text is written directly in each page.
- **Design** (colours, fonts, layout): `style.css`
- **Interactions** (map of areas, galleries, photo viewer, booklet viewer): `main.js`
- **Brand assets** from the visual identity: `assets/brand` and `assets/fonts`
- **Booklets** (PDF) from the MBRP project: `assets/booklets`
- **Photos**: `images/`

Click any photo to see it larger. To add a photo to a section, copy an existing `<figure class="fig ...">` block and change the file name and caption.

To publish on GitHub Pages: create a repository named `<your-username>.github.io`, upload all files, and the site will be live at `https://<your-username>.github.io`.
